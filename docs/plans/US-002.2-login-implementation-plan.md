### Phase 1: Setup

- [ ] Create `src/types/auth.ts` with User, LoginRequest, AuthResponse types
- [ ] Create `src/stores/authStore.ts` (Zustand) for user state and login status
- [ ] Create `src/hooks/useAuth.ts` hook for auth operations
- [ ] Create Protected route wrapper (`ProtectedRoute.tsx`) with redirect to login
- [ ] Configure environment: `VITE_API_BASE_URL`, `SESSION_TIMEOUT_DAYS=7`
- [ ] Create `src/utils/authApi.ts` with API client functions

### Phase 2: Implementation

**Backend Tasks:**

- [ ] Create `POST /auth/login` endpoint
  - Accept: email, password (validation with Zod)
  - Lookup user by email
  - Verify password with bcrypt.compare()
  - Return generic error on mismatch (prevent email enumeration)
  - Generate JWT token with 7-day expiration or session cookie
- [ ] Create `POST /auth/logout` endpoint (clear session)
- [ ] Create `GET /auth/me` protected endpoint (verify token, return user)
- [ ] Add authentication middleware (verify JWT/session on protected routes)
- [ ] Implement rate limiting on login endpoint (max 5 attempts per 15 min)
- [ ] Add error handling: invalid credentials, network errors, database errors
- [ ] Configure CORS for frontend domain

**Frontend Tasks:**

- [ ] Create `src/features/Auth/LoginPage.tsx` component
  - Email input field with validation
  - Password input with show/hide toggle
  - Submit button with loading state
  - Error message display (generic)
  - "Forgot Password?" link placeholder
- [ ] Integrate form with TanStack Query mutation
- [ ] Add Zod validation schema (email format, password required)
- [ ] Implement API error handling (distinguish network vs auth errors)
- [ ] On success: store token, update auth store, redirect to `/dashboard`
- [ ] Persist authentication state (token in secure storage)
- [ ] Add "Logout" button on dashboard/sidebar (callback: clear storage, redirect to `/login`)
- [ ] Mobile responsive: ensure inputs are large, tap targets > 44px (iOS), < 100% width
- [ ] Accessibility: ARIA labels, role="form", keyboard Tab order, focus management

**Session Management Tasks:**

- [ ] Implement secure token storage (httpOnly cookie preferred; fallback: localStorage with warnings)
- [ ] Auto-refresh token logic if using JWT
- [ ] Session expiration check: if token expired on protected route, redirect to login with message
- [ ] Add inactivity timeout (optional Phase 2+: auto-logout after 30 days)

## Constraints

- **Security:** No sensitive error details exposed; same error for invalid email/password
- **Performance:** Login response < 500ms on 3G (exclude network latency)
- **Session:** 7-day timeout non-negotiable for MVP
- **Accessibility:** WCAG 2.1 AA compliance required (keyboard, screen reader, color contrast)
- **Mobile:** Must work on iOS Safari and Android Chrome
- **No 2FA in MVP** (Phase 2+)

---

## Success Criteria

Acceptance Criteria Met:

- ✓ User can access login form from landing page
- ✓ Form requests email and password only (simple UI)
- ✓ Invalid credentials show generic error (no enumeration)
- ✓ Successful login redirects to dashboard
- ✓ Mobile-optimized form with keyboard-friendly inputs
- ✓ Session remains active for 7 days (configurable)
- ✓ Logout available with single click from any page

Definition of Done:

- ✓ Login endpoint created and unit + integration tested
- ✓ Session management tested (7-day timeout verified)
- ✓ Error handling covers: invalid credentials, network, rate limit
- ✓ Redirect logic verified (login → dashboard, logout → home)
- ✓ Mobile UX tested on iOS and Android
